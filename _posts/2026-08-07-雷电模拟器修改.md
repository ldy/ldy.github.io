# 雷电模拟器修改

> 开发的时候，雷电模拟器可以安装安卓应用方便调试，但雷电模拟器开屏、桌面、游戏中心等广告比较多，我们通过以下方式来去除广告。

## 开屏广告

由于开屏广告并不是模拟器里面安卓应用的广告，而是软件自身的广告，通过`Fiddler`抓包，屏蔽域名的方式来阻止广告显示。

![image-20260616115038138](https://cdn.jsdelivr.net/gh/ldy/ldy.github.io@master/screenshot/2026-08-07-%E9%9B%B7%E7%94%B5%E6%A8%A1%E6%8B%9F%E5%99%A8%E4%BF%AE%E6%94%B9-image-20260616115038138.png)

修改`C:\Windows\System32\drivers\etc\hosts`文件，添加以下内容。

```
127.0.0.1 api.ldmnq.com
127.0.0.1 res.ldmnq.com 
127.0.0.1 mnq-service.ldmnq.com
127.0.0.1 game-service.ldmnq.com
```

执行`ipconfig /flushdns`刷新`DNS`缓存再重启雷电模拟器发现广告没了。

![image-20260616115318347](https://cdn.jsdelivr.net/gh/ldy/ldy.github.io@master/screenshot/2026-08-07-%E9%9B%B7%E7%94%B5%E6%A8%A1%E6%8B%9F%E5%99%A8%E4%BF%AE%E6%94%B9-image-20260616115318347.png)

## 游戏中心

通过adb工具，执行 `.\adb.exe shell`，再执行`pm uninstall --user 0 com.android.flysilkworm`即可卸载游戏中心。

## 桌面应用

通过`mt管理器`安装包提取系统应用可以得知桌面启动器的包名为`com.android.launcher3`。

![image-20260615181923387](https://cdn.jsdelivr.net/gh/ldy/ldy.github.io@master/screenshot/2026-08-07-%E9%9B%B7%E7%94%B5%E6%A8%A1%E6%8B%9F%E5%99%A8%E4%BF%AE%E6%94%B9-image-20260615181923387.png)

![image-20260615181907048](https://cdn.jsdelivr.net/gh/ldy/ldy.github.io@master/screenshot/2026-08-07-%E9%9B%B7%E7%94%B5%E6%A8%A1%E6%8B%9F%E5%99%A8%E4%BF%AE%E6%94%B9-image-20260615181907048.png)

先安装**迷你桌面（启动器）**，在设置，应用和通知，默认应用中，将迷你桌面设置为主屏幕应用。

![image-20260616150455869](https://cdn.jsdelivr.net/gh/ldy/ldy.github.io@master/screenshot/2026-08-07-%E9%9B%B7%E7%94%B5%E6%A8%A1%E6%8B%9F%E5%99%A8%E4%BF%AE%E6%94%B9-image-20260616150455869.png)

通过adb工具，执行 `.\adb.exe shell`，再执行`pm uninstall --user 0 com.android.launcher3`即可卸载默认桌面。

![image-20260616150549585](https://cdn.jsdelivr.net/gh/ldy/ldy.github.io@master/screenshot/2026-08-07-%E9%9B%B7%E7%94%B5%E6%A8%A1%E6%8B%9F%E5%99%A8%E4%BF%AE%E6%94%B9-image-20260616150549585.png)
